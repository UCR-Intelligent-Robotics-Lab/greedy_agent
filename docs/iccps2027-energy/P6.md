# P6: registered energy-panel gates

Implements `gates.md` at tag `iccps2027-energy-gates`, commit
`4755ea5bd00c10ff937fde8b5efc3648d55dc497`. Every numerical threshold and
sampling setting is copied from that document into the single `REGISTRY` in
`sensys_runs/evaluate_gates.py`; every entry cites its source section.
No threshold is fitted to results. This change uses synthetic tests only and
opens no real result file. It changes no existing file.

## Usage

After summaries are independently validated, supply their directories, not
run directories. Each wave option accepts multiple directories, including
additional P4 evaluation-only hardware rescoring summaries. Paths below are
placeholders. The output directory must not exist.

```bash
python -B sensys_runs/evaluate_gates.py \
  --wave1 /path/to/wave1_summary /path/to/wave1_hetero_rescoring_summary \
  --wave2 /path/to/wave2_summary \
  --wave3 /path/to/wave3_summary \
  --out /path/to/fresh_gate_report
```

Omit any absent wave option. Its dependent comparisons are NOT_EVALUATED;
missing inputs never become a failure or a positive claim. The evaluator reads
only seed_metrics.csv and hardware_seed_metrics.csv, merging complementary
columns by the complete training/evaluation arm identity and seed. It does not
read summary.csv, episodes, checkpoints or real run directories. It recomputes
paired differences from matched seeds rather than trusting aggregate values.
Each consumed input file's SHA-256 and the pinned gates file's SHA-256 and
commit are recorded in gates_report.json and gates_report.md. The registered
tag must resolve to the pinned commit. Repeated conflicting records and
ambiguous reference arms are refused; identical complementary copies may merge.
Pairing requires identical complete registered seed sets before the explicit
no-lever exclusions. Smoke summaries are not formal gate inputs.

## Statistical implementation

Wilcoxon enumerates every sign assignment of doubled integer average ranks,
including ties. Exact zeros are dropped from ranks and counted; an all-zero
vector has p=1. Bootstrap medians and probabilities retain zeros. Percentile
intervals use NumPy's linear percentile interpolation and a fresh private
Generator with the registered seed for each comparison. They resample training
seeds only. CSV decimal subtraction preserves inclusive effect boundaries
without adding a numerical tolerance. Relative costs require positive reference
costs. Reports include per-seed differences, counts, exclusions, both cost
scales where needed, and every pass condition.

Holm always uses the full registered G1/G3a/G3b family. A missing or inconclusive
primary test conservatively occupies its slot with p=1; its reported adjusted
p remains null. Partial-data adjusted p values are recomputed when later waves
arrive. G1 combines the strict adjusted-p threshold, inclusive relative-cost
threshold and inclusive bootstrap success bound. G3 excludes no-lever seeds
per arm before intersecting valid paired shares, reporting both exclusion lists.
More than the registered limit in either arm makes G3 INCONCLUSIVE.
Non-detection is labeled NOT_DETECTED, never "no effect". Secondary/descriptive
comparisons have no pass line. The October 18 decision is reported separately;
G1 non-detection requests advisor discussion, and a G3 inconclusive state never
supports a routing claim.

G4 specifies metrics but no predicted direction in gates.md. The evaluator
therefore reports both one-sided tails and both directional improvement counts,
explicitly labeled as unspecified direction, without selecting a prediction or
inventing a pass threshold. G4's plain-LIO reference uses P5's accounting-only
training-profile exemption; evaluation table, hardware and seed matching remain
strict. REFiNE references retain training cost and hardware matching.

## Sanity reference and missing evidence

The homogeneous evaluator's share is undefined because there is no lower-lambda
group. To obtain the pre-registered agents-0/1 sanity reference, provide wave-1
homogeneous policies rescored with `--evaluation_hardware_profile
hetero_2x1p5_v1` by the existing summary tool. This changes accounting only.
Without those seed rows, sanity is NOT_EVALUATED, never silently replaced with
an all-agent share. Reported out-of-range medians flag agent-index asymmetry
before G3 interpretation; this sanity check is not an additional pass gate.
