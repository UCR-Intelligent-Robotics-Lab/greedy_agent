## Implementation

The registry is `sensys_runs/energy_profiles.py`, rather than the proposed
`lio/alg/energy_profiles.py`: `lio/alg/__init__.py` eagerly imports TensorFlow.
Keeping the registry outside that package preserves dependency-free CLI validation
and keeps agent imports after the existing runtime/thread setup.

`--cost_profile` defaults to `legacy`. The original class method and trainer execute
without new config or provenance fields. Existing legacy output handling is unchanged.

The three new profiles use mean-one vectors derived from exact source ratios:
`uniform_v1` (1), `low_contrast_v1` (9.2/7.5), `paper_ratio_v1` (1.75).
The registry records their source classification and action-mapping assumption.
Only the selected clean-ER class is patched, for the duration of its training call;
restoration occurs in `finally`. The cost lookup neither counts usage nor samples RNGs.
The existing agent `energy_param` must equal 1; an unregistered scale is an error.

New-profile runs reject EIA/IPD and existing output paths before writing. Exclusive
directory creation also rejects a competing creator. Profile snapshots are stored
in both the existing config output and provenance. `actor_cost_form=episode_mean`
describes REFiNE's retained penalty; LIO consumes the table for accounting only.

## Claim and validation boundary

P1 checks that the selected modeled cost reaches episode buffers and the actor's
energy-penalty feed. This is a strict software identity, not an energy-efficiency claim.
The probe executes the current source bodies for the episode, buffer and update;
it does not substitute a reimplementation of their accounting.

Local validation: 23 passed, 1 skipped. The skipped test requires TensorFlow.
The passing launcher tests use a stub trainer and do not establish graph execution.
The scripted two-step mission changes agent 0's total/feed from 2.0 (uniform) to
2.2 (paper ratio), while exercising the unused cost call without double counting.
Checks also cover provenance, default dispatch, bad inputs, stale-output refusal,
state independence, RNG purity and exception restoration.
