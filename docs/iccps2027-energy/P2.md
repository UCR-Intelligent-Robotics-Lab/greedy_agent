## New output and provenance

`sensys_runs/energy_profile_eval.py` calls the existing `test_room_symmetric`
with `config.alg.n_test` (currently 100). A temporary `env.step` observer forwards
arguments and returns the original result, without sampling RNGs. It restores
the original method on success and on exceptions, including its class/instance
lookup behavior. Terminal code 1 means success; code 2 means timeout.

The schema has one definition, `EPISODE_FIELDS`, and writes one row per completed
episode and agent to `energy_eval_episodes.csv`. Columns are:

```text
schema_version,run_id,seed,method,training_profile,checkpoint_episode,
eval_episode,agent_id,terminal_code,steps,n_lever,n_start,n_door,env_return
```

`energy_eval_provenance.json` records the complete effective config, training and
evaluation profile snapshots, configured training episode, exact final checkpoint
prefix and SHA-256 hashes of its index, graph and data shards, plus the CSV hash.
The existing launcher's `provenance.json` continues to hold code/platform identity.
The two new files are created exclusively after all requested episodes complete.
Existing files are refused; failed evaluation leaves no sidecar. An interrupted
write without a matching manifest cannot pass the summary reader.

The unchanged evaluator indexes its fairness list once per agent. The new entry
therefore rejects `n_test < n_agents` explicitly; no evaluator repair is bundled.

## Summary semantics

`sensys_runs/summarize_energy_profiles.py` reads exact run directories and verifies
schema, identity, completeness, checkpoint hashes and CSV hash. It rejects missing
or duplicated agent rows, inconsistent termination, invalid counts and non-finite
returns. All three cost tables score the same recorded trajectories offline.

- Success and mean steps use evaluation episodes as the denominator.
- Mean agent mission cost and environment return average all episode/agent rows.
- Failed missions are included. Environment return excludes incentives.
- Worst-agent cost is the maximum of identified agents' episode-mean costs.
- Each cost splits into `b * mean_steps` and `d * mean_support_actions`.
- `seed_metrics.csv` preserves independent training-seed observations.
- `summary.csv` averages seed-level metrics and reports the number of seeds.
- `paired_differences.csv` compares REFiNE arms against available LIO and uniform
  REFiNE references, within the same evaluation table and identical seed sets.
  All deltas are method minus reference; step and support deltas sum to cost delta.
- `inputs.json` records input manifest hashes, units, profiles and conventions.

The summary requires a common environment, architecture and evaluation protocol,
and identical training settings across seeds within each arm. It does not compute
confidence intervals or treat evaluation episodes as independent training seeds.
Existing summary directories are refused. Failed inputs are reported before any
summary output is created.

From the repository root, after real runs exist:

```bash
python -m sensys_runs.summarize_energy_profiles --runs <run-dir-1> <run-dir-2> --out <fresh-summary-dir>
```
